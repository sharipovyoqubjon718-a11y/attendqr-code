# Нақшаи тоҷикӣ кардани шарҳҳои тамоми лоиҳа

## Ҳадаф
Ҳамаи файлҳои матнии манбаъ ва танзимоти дастиро омӯзишӣ гардондан: дар аввали ҳар файл шарҳи равшани тоҷикӣ гузошта мешавад ва шарҳҳои мавҷуда ба тоҷикӣ тарҷума мешаванд, бе тағйири рафтори барнома.

## Корҳо
1. Файлҳои барнома (`src`), функсияҳои абрӣ, санҷишҳо, service worker ва файлҳои танзимотии шарҳпазирро гурӯҳбандӣ мекунам.
2. Ба аввали ҳар файли TypeScript, TSX, JavaScript, CSS, SQL, HTML ва файлҳои дигари шарҳпазир ҷамъбасти махсуси тоҷикӣ илова мекунам: вазифа, мақсад ва нақши он дар лоиҳа.
3. Ҳамаи шарҳҳои англисӣ ё омехтаи мавҷударо ба тоҷикӣ тарҷума мекунам; номҳои рамзӣ, матни интерфейс, фармонҳо, URL-ҳо ва мантиқи барнома бетағйир мемонанд.
4. Файлҳои JSON, lock-файлҳо ва TOML-и худкорро тағйир намедиҳам, зеро формати онҳо шарҳро иҷозат намедиҳад ё тағйир доданашон метавонад насб/танзимотро вайрон кунад. Файлҳои бинарӣ ва файлҳои худкорсохтаи пайвасти абрӣ низ истисно мешаванд.
5. Пас аз тағйирот санҷишҳои мувофиқро иҷро карда, ҷустуҷӯ мекунам, ки шарҳҳои англисии боқимонда дар файлҳои фарогирифташуда набошанд.

## Қоидаи навиштан
- Забон: тоҷикии равон ва касбӣ.
- Ҷамъбаст: кӯтоҳ, вале махсус ба вазифаи ҳамон файл.
- Шарҳҳо: маънои техникиро дақиқ нигоҳ медоранд.
- Код: танҳо шарҳҳо тағйир меёбанд; фаъолияти барнома ва маълумот тағйир намеёбад.

## Фарогирӣ
Тақрибан 120+ файли матнии шарҳпазир, аз ҷумла саҳифаҳо, қисмҳо, китобхонаҳо, UI, санҷишҳо, функсияҳои абрӣ ва муҳоҷиратҳои SQL.
